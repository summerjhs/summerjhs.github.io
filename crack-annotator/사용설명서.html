균열 어노테이션 툴 — 실행 설명서

드론으로 촬영한 아파트 외벽 이미지에서 균열·창·기타하자를 표시하는 작업 툴입니다. 별도 설치 없이 브라우저에서 바로 동작하며, 작업 결과는 폴더 안에 자동 저장됩니다.

필요 브라우저 Chrome / Edge 운영체제 Windows 설치 불필요 인터넷 불필요
1

준비물

  1. Chrome 또는 Edge 브라우저 — 다른 브라우저(Firefox·Safari 등)는 폴더 저장 기능을 지원하지 않습니다.
  2. 받은 압축파일 균열어노테이터_배포.zip — 이 툴 프로그램입니다.
  3. 배정받은 섹션 폴더 — 이름이 …_SUPR 로 끝나는 촬영 폴더. 안에 *_0000_SUPR.JSON, *_0000_W.JPG 와 여러 장의 이미지가 들어 있습니다.
2

실행 — 3단계

STEP 01

압축 풀기

받은 .zip 을 마우스 우클릭 → 압축 풀기. 균열어노테이터 폴더가 생깁니다.

STEP 02

start.bat 더블클릭

폴더 안 start.bat 실행. 검은 창이 뜨고 잠시 후 브라우저가 자동으로 열립니다.

STEP 03

섹션 폴더 열기

상단 📂 섹션 폴더 열기 → 배정받은 폴더 선택 → 권한 팝업 “편집 허용”.

⚠ 알아두세요. 브라우저가 자동으로 안 열리면 주소창에 http://localhost:8796 를 직접 입력하세요. “이 앱이 차단되었습니다” 경고가 뜨면 추가 정보 → 실행을 누르면 됩니다. 검은 창은 작업하는 동안 계속 켜 두세요(닫으면 툴이 종료됩니다).
✔ 저장 위치. 작업 결과는 선택한 섹션 폴더 안 labels/ 폴더에 자동으로 저장됩니다. 다음에 같은 폴더를 다시 열면 이어서 작업할 수 있습니다.
3

화면 보기 & 격자 색

폴더를 열면 상단에서 두 가지 보기를 전환할 수 있습니다 — 🗺️ 전경격자(전체 벽면 위에 격자 표시) · 🖼️ 이미지나열(썸네일 목록). 각 칸(이미지)의 색으로 작업 상태를 알 수 있습니다.

회색 · 미작업
초록 · 균열·창·기타 라벨 있음
노랑 · 검토완료(라벨 없음)

목표: 모든 칸을 초록(라벨 그림) 또는 노랑(라벨 없음 확인)으로 만들면 그 섹션 작업 완료입니다.

4

어노테이션 방법

  1. 격자/썸네일에서 칸을 클릭하면 편집 화면이 열립니다.
  2. 왼쪽에서 클래스를 고릅니다 — ● 균열(1) ● 창(2) ● 기타하자(3).
  3. 폴리곤 P: 대상 외곽을 따라 클릭해 점을 찍고, Enter 또는 더블클릭으로 완성합니다. 가늘고 긴 균열은 외곽선을 따라 여러 점으로 감싸면 됩니다.
  4. 박스 B: 드래그해서 사각형으로 표시(창 등 네모난 대상에 편리).
  5. 수정: 점을 드래그해 이동, Insert 또는 ＋점으로 점 추가, 점/객체 선택 후 Del 삭제. 왼쪽 라벨 리스트에서 항목 클릭=그 위치로 이동, ✕=삭제.
  6. 화면 조작: 빈 영역 드래그=화면 이동, 마우스 휠=확대/축소, F=화면 맞춤.
  7. 라벨이 원본을 가려 잘 안 보일 때 👁 라벨 또는 H — 채움 → 외곽선만 → 숨김 순으로 전환됩니다(원본 균열 확인용).
5

저장 & “확인(무라벨)”

▸라벨을 그린 이미지

💾 저장 또는 S 로 저장 → 격자에서 초록으로 표시됩니다.

▸균열이 없는 이미지

그리지 말고 ✓ 확인(무라벨) 클릭 → 노랑(검토완료). 격자에서 칸을 우클릭해도 토글됩니다.

중요. 균열이 없어도 “확인(무라벨)”로 검토했음을 꼭 표시해 주세요. 회색(미작업)으로 남아 있으면 아직 안 본 이미지로 처리됩니다.

7

결과 회신

작업이 끝나면 섹션 폴더 안에 생긴 labels/ 폴더(또는 섹션 폴더 전체)를 압축해서 담당자에게 회신해 주세요. 폴더 이름(…_SUPR)은 그대로 두시면 됩니다.

회신 전 확인. 격자에 회색(미작업) 칸이 없는지 한 번 더 살펴봐 주세요 — 모두 초록/노랑이면 완료입니다.
8

문제 해결 (자주 묻는 질문)

Q이미지가 안 보여요.

반드시 start.bat 으로 실행해야 합니다. index.html 을 직접 더블클릭하면(file://) 폴더 기능이 막혀 이미지가 나오지 않습니다. Ctrl+Shift+R 로 새로고침도 시도해 보세요.

Q“섹션 폴더 열기”를 눌러도 반응이 없어요.

Chrome 또는 Edge 인지 확인하세요. 폴더 선택 후 뜨는 권한 팝업에서 “편집 허용”을 눌러야 합니다.

Q저장이 안 돼요.

폴더 권한을 “편집 허용”으로 허용했는지 확인하세요. 허용해야 labels/ 폴더에 결과를 쓸 수 있습니다.

Q“이 앱이 차단되었습니다” 경고가 떠요.

Windows 기본 기능만 사용하는 안전한 프로그램입니다. 추가 정보 → 실행을 누르면 됩니다.

Q확대했는데 다른 부분을 못 봐요.

확대 상태에서 빈 영역을 드래그하면 화면이 이동합니다. F 로 전체 화면에 맞출 수 있습니다.
