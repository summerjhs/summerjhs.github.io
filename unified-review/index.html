❔ 사용법 · 지원 포맷

1. 파일 불러오기
① 이미지 폴더 → 이미지가 든 폴더를 선택합니다.
② 라벨 폴더 → 라벨(.txt/.xml/.json)이 든 폴더를 통째로 선택합니다. 라벨 파일(COCO 등) → COCO JSON 한 개처럼 파일을 직접 고를 때 사용합니다. 확장자로 포맷을 자동 판별하며, 이미지와는 확장자를 뺀 파일명으로 매칭합니다 (a.jpg ↔ a.txt / a.xml / a.json, a.jpg.txt도 인식).
클래스 이름 → YOLO처럼 클래스가 숫자인 경우 .txt/.yaml/.json으로 이름을 지정합니다. VOC·LabelMe·COCO·labelit.pro는 라벨에 이름이 들어 있어 자동 등록됩니다.
labelit.pro 결과 파일은 한 줄에 이미지 한 장(JSONL)인 형식이라 일반 JSON 뷰어에서는 열리지 않는데, 이 툴은 그대로 읽어 importData_file_name으로 이미지와 매칭하고 info.assets에 정의된 라벨 필드(예: label_symbol)를 클래스로 씁니다.
2. 모아보기 / 필터
클래스·유형·라벨 유무·오류 필터로 원하는 대상만 모아 봅니다. 범례(색 칩)를 클릭하면 해당 클래스/유형을 화면에서 숨기거나 다시 보여줍니다.
🔍 라벨 영역만을 켜면 어노테이션이 있는 부분만 잘라서 크게 보여줍니다(전체 이미지에 비해 객체가 작을 때 유용). 끄면 다시 전체 이미지가 보입니다. 격자·확대 화면·PPTX 내보내기에 모두 적용됩니다.
🔬 객체 모아보기는 객체 하나하나를 크롭해 카드로 늘어놓아, 같은 클래스끼리 라벨 품질을 비교하기 좋습니다. 카드를 클릭하면 원본 이미지의 해당 객체가 선택된 상태로 열립니다.
3. 검수
이미지를 클릭해 확대한 뒤 객체를 클릭하면 오른쪽 패널에서 오류 종류를 고르고 메모를 남길 수 있습니다. 객체가 없는 곳을 더블클릭하면 그 좌표에 '객체 누락' 지점을 찍습니다.
✎ 클래스 수정은 좌표·형상은 그대로 두고 클래스만 바꿉니다. 🗑 객체 삭제도 가능합니다. 수정한 내용은 💾 수정 라벨 저장으로 원본과 같은 포맷으로 내보냅니다 (YOLO·VOC·LabelMe는 ZIP, COCO는 JSON 한 개).
4. 내보내기
오류 PPTX — 오류가 있는 이미지를 슬라이드로 (이미지 + 오류 목록).
오류 CSV — 이미지·객체·오류 종류·정답 클래스·메모 표.
검수기록 저장/불러오기 — 오류 기록을 JSON으로 백업하거나 다른 PC에서 이어서 검수. (기록은 브라우저 localStorage에도 자동 저장됩니다.)
